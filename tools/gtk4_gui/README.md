# gtk4_gui

GTK front-end workspace for Adi_GUI. The project is named `gtk4_gui` to match the requested UI direction, but the current GtkAda binding available from Alire is the standard GtkAda package set for GTK 3, which is the installable and buildable runtime in this environment.

This directory is intentionally minimal: a ready-to-extend Ada GUI scaffold for the future GTK front-end implementation.

## Build

```sh
cd tools/gtk4_gui
alr build
./gtk4_gui
```
